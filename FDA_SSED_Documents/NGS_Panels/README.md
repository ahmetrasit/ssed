## Download Instructions

### Method 1: Direct Browser Download
1. Click on each URL above
2. Your browser should prompt to download the PDF
3. Save with the suggested filename in this folder

### Method 2: Command Line (with FDA access)
```bash
# Navigate to this folder
cd FDA_SSED_Documents/NGS_Panels/

# Download FoundationOne CDx documents
wget -O FoundationOne_CDx_P170019_Original_SSED.pdf "https://www.accessdata.fda.gov/cdrh_docs/pdf17/p170019b.pdf"
wget -O FoundationOne_CDx_P170019_S029_SSED.pdf "https://www.accessdata.fda.gov/cdrh_docs/pdf17/P170019S029B.pdf"
wget -O FoundationOne_CDx_P170019_S048_SSED.pdf "https://www.accessdata.fda.gov/cdrh_docs/pdf17/P170019S048B.pdf"

# Download Oncomine Dx Target Test
wget -O Oncomine_Dx_Target_P160045_Original_SSED.pdf "https://www.accessdata.fda.gov/cdrh_docs/pdf16/p160045b.pdf"

# Download TruSight Oncology Comprehensive
wget -O TruSight_Oncology_Comprehensive_P230011_Technical_Info.pdf "https://www.accessdata.fda.gov/cdrh_docs/pdf23/P230011C.pdf"
```

### Method 3: FDA PMA Database Search
1. Go to: https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfPMA/pma.cfm
2. Enter PMA number (e.g., P170019)
3. Click "SSED" or "Summary" button to download
4. For supplements, look for supplement list on device page
